# 小红书 — 发布笔记

配 demo 图（hero.png / 监控墙截图）。人设：独立开发者给 AI 程序员做工具。已过广告法合规审查（无绝对化用语）。

---

**标题**

把吃灰的旧手机，变成 AI 写代码的"状态屏"👀（再也不用切窗口看跑完没）

**正文**

每次用 AI 写代码最烦的就是——它到底跑完了没？是在干活、在等我点确认、还是早就空闲了？我得一遍遍切窗口去瞅，特别打断思路😮‍💨

我是个独立开发者，平时全靠 AI agent 写代码（Claude Code、Codex、Cursor 这些）。于是自己撸了个小工具，叫 Awaitlight，专治这个。

它干嘛的👇
把你抽屉里吃灰的旧手机，变成 AI agent 的"状态屏"。

✅ 一眼看状态：在跑 / 在思考 / 等你操作 / 空闲，用一圈会发光的"光环"显示，横屏摆桌上扫一眼就懂
✅ 顺带能看：上下文窗口剩多少、5 小时和每周的用量额度、用的什么模型、花了多少钱
✅ 同时开好几个 agent？自动拼成一面"监控墙"，谁忙谁闲一目了然
✅ 没活干时，屏幕上有个我自己画的像素小伙伴在溜达，还挺治愈的🐾

为什么我自己天天用👇
🔒 纯本地运行，默认不上传任何数据
⚙️ 零配置，自动读本地 session 文件，不用注册、不用云、没有埋点
🧩 极轻量，跑个很小的 Node 服务，手机和电脑连同一个 Wi-Fi，打开打印出来的地址就行
🎨 好几套配色主题，中英文都支持

而且它开源 + 免费（MIT 许可，随便用，商用也行）。用了一阵子，现在离了它还有点不习惯🤏 UI 还有点糙，但够用。

📌 怎么开始：
GitHub 搜 Awaitlight/awaitlight，或者去 awaitlight.com 看看，欢迎来提 issue～

（小声说：它是个独立项目，跟 Anthropic、OpenAI、Cursor 都没关系，只是能配合它们用而已～）
