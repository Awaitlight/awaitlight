**1/** I stopped alt-tabbing to check if Claude was done. My old phone now sits on my desk as an ambient status light for my AI coding agents — one glance tells me if each one is running, thinking, or waiting on me.

**2/** It reads your local session files, so it works with Claude Code, Codex, Cursor, and Claude Cowork out of the box. No app to install, no account. (It's an independent project — not affiliated with or endorsed by any of them.)

**3/** At a glance it shows agent state (running / thinking / waiting-on-you / idle), context-window left, your 5-hour & weekly usage limits, model, and cost. Got several agents going? They tile into a monitoring wall. When everything's idle, a little pixel companion plays on screen.

**4/** Setup is one command: run a tiny zero-dep Node server on your machine, then open the printed LAN address on a spare phone on the same Wi-Fi, in landscape. That's it. It's fully local — talks only to your own phone over Wi-Fi. No cloud, no telemetry. Multiple themes, English + Chinese.
