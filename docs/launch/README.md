# Launch kit

Ready-to-post copy for getting Awaitlight in front of people. You post these yourself — timing and real accounts are on you; the words are done.

- [show-hn.md](show-hn.md) — **the big one.** Hacker News is the #1 organic-traffic source for developer tools; one good Show HN can do more than everything else combined.
- [reddit.md](reddit.md) — r/ClaudeAI (primary), r/LocalLLaMA.
- [x-thread.md](x-thread.md) — build-in-public thread for @awaitlight.
- [xiaohongshu.md](xiaohongshu.md) — 小红书 笔记（中文）.

**Suggested sequence** (don't blast all at once — space them out over a few days):

1. Make sure the repo looks alive: README with the demo image, a clear description, topics. ✅
2. **Show HN** — a weekday, ~8–10am US Pacific. Then stay in the thread for a few hours and reply to every comment. This is the one that matters.
3. Reshare on **X** and **Reddit** a day or two later.
4. **小红书** for the Chinese audience.

Demo image lives at [`docs/hero.png`](../hero.png). A short screen-recorded GIF of the halo changing state would convert even better — worth adding when you can.
